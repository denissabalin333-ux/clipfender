ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ

Версия от 22 сентября 2026 года.

Эта политика описывает, какие данные обрабатывает ClipFender, для чего они нужны и как пользователь может удалить свои данные. Текст является информационным документом и не заменяет юридическую консультацию.

1. Кто обрабатывает данные

Оператором сервиса является владелец и оператор ClipFender. Юридическое наименование и адрес оператора должны быть указаны владельцем сервиса перед публикацией там, где это требуется применимым правом.

2. Какие данные мы обрабатываем

Для аккаунта: имя, email, хэш пароля, сессии и технические данные, необходимые для безопасности. Для библиотеки: избранное, коллекции, историю поиска и сохранённые фильтры. Для контактов: имя, email, текст сообщения, технический IP-адрес и user-agent.

ClipFender не запрашивает логин или пароль YouTube и не получает доступ к приватным данным YouTube от имени пользователя.

3. YouTube API

Поиск и отображение материалов используют YouTube API Services. Неавторизованные API-данные, которые временно кэшируются для поиска, удаляются локальным cache cleanup в течение 24 часов. Это не должно рассматриваться как замена требованиям YouTube: применяются актуальные Terms of Service и Developer Policies.

Официальные документы: YouTube API Services — Developer Policies и YouTube API Services Terms of Service (EMEA).

4. Cookies и локальное хранилище

Для входа используются httpOnly session cookie и CSRF cookie. Локальное хранилище браузера используется для интерфейсных настроек и локального fallback избранного. При включении необязательной аналитики сторонний analytics script загружается только после согласия пользователя.

5. Аналитика

ClipFender может использовать Plausible только при явном включении оператором через переменную окружения. При включённой аналитике пользователь видит отдельное уведомление и может отказаться. По умолчанию аналитика выключена.

6. Сроки хранения

Аккаунт и связанные с ним библиотечные данные хранятся до удаления пользователем или оператором в соответствии с применимым правом. Сессии имеют ограниченный срок. Логи и rate-limit технически удаляются по политике эксплуатации. YouTube API cache и состояние поиска очищаются примерно через 24 часа.

7. Удаление данных

Вошедший пользователь может удалить аккаунт из раздела «Моя библиотека». При подтверждении паролем удаляются аккаунт, сессии, избранное, коллекции, история поиска и сохранённые фильтры. Контактные обращения, которые оператор обязан хранить по закону, могут сохраняться в пределах обязательного срока.

8. Изменения политики

Политика может обновляться при изменении функциональности или требований закона. На странице указывается дата последней версии.

9. Контакты

Для вопросов о конфиденциальности используйте форму контактов.
