CLIPFENDER FINAL PUBLIC RELEASE — RENDER FREE + TURSO

Canonical deployment:
  Render Free web service (FastAPI)
  Turso Cloud for persistent SQLite-compatible production storage
  Generated character portraits stored as BLOBs in Turso

Launch locally:
  Git Bash: ./start_git_bash.sh
  Windows:  start_windows.bat

Docker:
  ./start_docker.sh
  start_docker.bat

Production:
  Use render.yaml. No Render Persistent Disk is required.
  Set TURSO_DATABASE_URL and TURSO_AUTH_TOKEN in Render.

Secrets:
  Never commit .env. Use Render Environment Variables in production.

Required production secrets:
  YOUTUBE_API_KEY
  TURSO_DATABASE_URL
  TURSO_AUTH_TOKEN
  ALLOWED_ORIGINS
  PUBLIC_BASE_URL
  ADMIN_EMAILS
  ADMIN_BOOTSTRAP_PASSWORD (remove after first successful bootstrap)
  OPENAI_API_KEY (required for automatic character portrait generation)

Release checks:
  pytest PASS
  Python compile PASS
  JS syntax PASS
  deployment config PASS
  secret scan PASS
  DB SHA-256 unchanged
